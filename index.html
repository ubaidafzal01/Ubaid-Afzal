Mealopia

Food & grocery delivery platform

Live in ChiniotFounder

My own startup. Customers order food and groceries from local restaurants and stores, and nearby riders deliver them. I designed and built the whole ecosystem end to end: four Flutter apps (Customer, Restaurant, Rider and Admin) sharing one Dart package, powered by a Firebase backend.

What I built

  • Event-driven backend on Cloud Functions: Firestore triggers for order notifications, a rider-matching engine that ranks nearby riders fairly and sends them offers, and scheduled jobs that re-offer stale orders.
  • Server-side money logic: delivery fees, commissions, payouts and rider cash settlement as pure, unit-tested modules with transactional, idempotent writes and audit logs.
  • Secure by default: deny-by-default Firestore rules with least-privilege access per collection and role-based admin access.
  • Real-time everything: live order status and push notifications (FCM) across the apps.
  • Admin panel for orders, restaurants, riders, payouts, the cash ledger, support and audit logs.
  • Marketing website at mealopia.com built with Next.js, Tailwind and Framer Motion.

C++ Quiz Game

Terminal Trivia · console quiz application

University · 2nd semesterTeam of 3

A full console quiz application written in C++ for our second-semester project. Questions are loaded from text files at runtime, and everything (questions, high scores, game logs) is saved to files.

Features

  • 5 categories (General Knowledge, Science, and more), 10 questions per game with a 10-second timer per question.
  • 3 difficulty levels with different penalties for wrong answers (−2, −3 and −5 points).
  • Lifelines, each usable once: 50/50, Skip and Swap question.
  • Single-player and 2-player head-to-head mode on the same console.
  • Randomised questions, streak tracking and input validation so bad input never crashes the game.

My part

  • Leaderboard: loads player scores from file, sorts them and shows the top 5.
  • Admin mode for adding new questions to the question files.
  • Game review at the end of each round, showing every question, your answer and the correct one.
  • Activity log that records each game automatically.

Laham Cattle Farm

Showcase website for a local farm

Client projectBuilt for a local business

A modern multi-page website I built for a local customer's cattle farm, to present their Qurbani animals and premium halal meat supply and make it easy for buyers to get in touch.

Features

  • Six pages: Home, About, Services, Gallery, Location and Contact, built with the Next.js App Router.
  • Animated hero and sections using Framer Motion, plus animated counters (years of experience, cattle, happy customers).
  • Contact form with React Hook Form and Zod validation that sends enquiries by email through EmailJS.
  • Location page with an embedded Google Map so customers can find the farm.
  • Fully responsive, styled with Tailwind CSS, with reusable typed components.
